# Реклама вебинара «Вступ до Словаччини» — монтаж

Исходник: говорящая голова, 43.4 с, 464×848, украинский. Результат: 1080×1920, 30 к/с, ~38.6 с, −14 LUFS.

## Конвейер
1. `work/edl.py` — EDL: какие куски речи оставить (паузы вырезаны, 43.4 → 36.2 с) и тайминги слов в выходном времени (`words.json`).
   Слова: текст — Whisper turbo (uk), тайминги — GigaAM v2 (sherpa-onnx), выравнивание по символам (`words_raw.json`).
2. `work/voice.py SRC work/build/voice.wav` — склейка голоса с микрофейдами + обработка (HPF, шумодав, EQ, де-эссер, компрессор).
3. `work/prep.py` (env `SRC`, `STOCK`, `OUT=hf/assets/media`) — спикер по EDL и B-roll: кроп 9:16, апскейл до 1080×1920, грейд, зерно.
4. `work/make_comp.py` — собирает `hf/index.html` из `work/index.src.html`: сцены, B-roll, субтитры (1–3 слова, активное слово жёлтым).
5. `work/mix.py hf/assets/audio/mix.wav` (env `STOCK`) — голос + музыка с дакингом под речь + SFX, двухпроходный loudnorm −14 LUFS / −1.5 dBTP.
6. `cd hf && npx hyperframes render -o ../out/….mp4 --quality delivery`

Медиа (mp4/wav) в git не лежат — пересобираются скриптами.
