# План кадров — 4 рилса (черновик на утверждение)

Исходники (work/takes = hair-ads/material):
- L48 = luda_3348 (короткое мелированное каре, мастер с круглой брашинг-щёткой, 60 к/с, HDR)
- L36 = luda_3336 (съёмка сверху, укладка феном; много мусорных кусков)
- LD  = leda_2235 (длинные гладкие золотистые волосы со спины, движение, 60 к/с, SDR)
- R8  = root_8e8d (смонтированный ролик: «до» волнистые → нанесение → утюжок → результат → мастер и клиентка в зеркале)
- RA  = root_a11e (смонтированный ролик: фен крупно → мастер расчёсывает → утюжок → руки по гладким волосам)
- C64, C65 = cam_2264/2265 (результат со спины, лёгкое движение)
- C66 = cam_2266 (клиентка на стуле дома, руки мастера разглаживают длинные волосы)
- C75 = cam_2275 (руки в волосах, взмах; 60 к/с → слоу-мо)
Сток (Mixkit, бесплатная коммерческая лицензия): 4283 Альпы таймлапс (4K), 48502 заснеженная деревня шале (720p → только в рамке), 31407 утро у окна (4K), 4948 чтение книги (4K).
