# R3 — 6 эстетичных рилсов (EN), статус для продолжения работы

Сборка: `segs.sh`/`seg1.sh` → seg/*.mp4 (грейд, 1080×1920) · `blur.sh` → *_bl.mp4 · `python3 build.py [id]` → r3/<id>/index.html
→ `hyperframes check <id>` → `hyperframes snapshot` → рендер `render.sh <id>` → out/r3/{music,nomusic}/<id>.mp4

| id | идея | ключевое слово CTA | музыка (Mixkit) |
|---|---|---|---|
| winter | горы против волос, холод → тепло | WINTER | 640 |
| arrival | POV: салон приехал, окно-разворот → мир | HOME | 144 |
| glass | тренд glass hair, блики, монтаж под бит | GLASS | 132 |
| alena | мастер — лицо бренда, имя за спиной | ALENA | 701 |
| words | цитата клиентки «в долине никто не делает» | VALLEY | 640 (другой отрезок) |
| classic | эволюция 01 DESIRE: SMOOTH/SILKY/GLOSSY, до/после линией | HAIR | 701 (другой отрезок) |

Статус: все 6 готовы (out/r3), стыки без скачков, проверены покадрово.

Критерии «идеала»: нет рваных стыков, текст не на лицах и в зоне 168–1330 px, каждое слово держится ≥0.5 с + 0.3 с/слово,
финал ≥3 с, check без ошибок, кадр 0 = обложка (волосы + заголовок).
