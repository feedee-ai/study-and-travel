# Study and Travel — два ролика со студенткой в Словакии

Исходники: Google Drive, 12 вертикальных клипов IMG_1975…IMG_1987 (HEVC HLG HDR, 1080×1920). В git не лежат.
- **v1 «Чек-лист»** (1975–1982), ~50.9 с: «4 речі про безкоштовний вступ» — чек-лист из 4 пунктов наверху, бейдж «Вступила з Study and Travel»,
  «Безкоштовно» с монетой, флаг Словакии и буквы с диакритикой, плашка «Вступні іспити → Без іспитів» и бегущие строки специальностей,
  календарь дедлайнов, евродиплом, вставка-монтаж «міжнародний досвід» (Mixkit 8954, 4683), финальная карточка «Детальніше».
  Дубль 1980 не используется (тот же текст, что 1981). Факт «А головне» (1979) стоит последним — по смыслу, фраза восстановлена целиком.
  Вырезано: «а не сподіватися, що якось вийде», «з урахуванням її сильних сторін…», «і допомоги на місці». Ускорение 1.12×.
- **v2 «Мрія → реальність»** (1983–1987), ~46.3 с: хук-вопрос, бейдж студентки, бенто из 4 преимуществ, «0 €», вставка студентов
  (Mixkit 8900, 5937) на «дитина не буде одна», чат с куратором (заселение),
  «РЕАЛЬНІСТЮ», футаж уходит в карточку на жёлтом фоне со степпером этапов, форма заявки. Субтитры — на плашках. Ускорение 1.10×.

## Сборка
```
python3 -I work/edl.py                                  # EDL + слова (Parakeet v3) → v1/edl.json, v2/edl.json
SRC=<папка с MOV> python3 -I work/prep.py v1|v2          # подложка (HLG→SDR, 30 к/с, ускорение) + голос (шумодав, EQ, компрессор)
STOCK=<папка со стоком> python3 -I work/broll.py               # вставки из стока
python3 -I work/make_comp.py v1|v2                       # v*/hf/index.html из v*/index.src.html + work/common.css
STOCK=<папка со стоком> python3 -I work/mix.py v1|v2     # голос + музыка с дакингом + SFX, −14 LUFS
cd v1/hf && npx hyperframes render -o ../../out/render_v1.mp4 --quality delivery
```
Распознавание: sherpa-onnx `nemo-parakeet-tdt-0.6b-v3` (мультиязычная, украинский) → `work/asr_parakeet.json`.
