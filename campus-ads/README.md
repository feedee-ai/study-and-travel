# Study and Travel — два ролика с кампуса UKF (Нітра)

Исходники: Google Drive, 12 вертикальных клипов IMG_1975…IMG_1987 (HEVC HLG HDR, 1080×1920). В git не лежат.
- **v1 «Чек-лист»** (1975–1982), 49.5 с: «4 речі про безкоштовний вступ» — чек-лист из 4 пунктов наверху, на каждый факт своя инфографика
  (уровень языка, перечёркнутый экзамен со штампом, календарь дедлайнов, евродиплом), маршрут, финальная карточка с кнопкой «Детальніше».
  Дубль 1980 не используется (тот же текст, что 1981). Факт «А головне» (1979) стоит последним — по смыслу.
  Вырезано ради 50 с: «а не сподіватися, що якось вийде», «з урахуванням її сильних сторін…», «і будувати власне майбутнє», «і допомоги на місці». Ускорение 1.12×.
- **v2 «Мрія → реальність»** (1983–1987), 46.6 с: хук-вопрос, бенто из 4 преимуществ, «0 €», аватары «не одна», карточка куратора,
  «РЕАЛЬНІСТЮ», футаж уходит в карточку на жёлтом фоне со степпером этапов, форма заявки. Субтитры — на плашках. Ускорение 1.10×.

## Сборка
```
python3 -I work/edl.py                                  # EDL + слова (Parakeet v3) → v1/edl.json, v2/edl.json
SRC=<папка с MOV> python3 -I work/prep.py v1|v2          # подложка (HLG→SDR, 30 к/с, ускорение) + голос (шумодав, EQ, компрессор)
python3 -I work/make_comp.py v1|v2                       # v*/hf/index.html из v*/index.src.html + work/common.css
STOCK=<папка со стоком> python3 -I work/mix.py v1|v2     # голос + музыка с дакингом + SFX, −14 LUFS
cd v1/hf && npx hyperframes render -o ../../out/render_v1.mp4 --quality delivery
```
Распознавание: sherpa-onnx `nemo-parakeet-tdt-0.6b-v3` (мультиязычная, украинский) → `work/asr_parakeet.json`.
