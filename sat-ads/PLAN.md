## Исходники
- Google Drive (ZIP экспорта Telegram) скачан через Apify → `sat-ads/material/raw/` (в .gitignore; в git не класть).
  Если контейнер новый и папки нет: Apify-актор `nerolabs~bulk-file-downloader` с URL
  `https://drive.usercontent.google.com/download?id=18NQNI4Ir3TM7SwUa968TjBGHEv28JwR5&export=download&confirm=t`,
  затем `unzip -j` только `files/*.MOV` и `video_files/*.mp4` в `material/raw/`. Чат (messages.html) не читать.
- Расшифровка: `sat-ads/material/transcript.json` (Parakeet v3 через sherpa-onnx; модель с GitHub-релиза k2-fsa, `/opt/asr`). Скрипт `work/asr.py`.
- Сеть: HF, jsdelivr, mixkit, openverse, instagram CDN закрыты. Google Fonts, npm, pypi, GitHub, Apify — открыты.
  → Музыки нет (нет источника) — ролики с голосом + встроенные SFX HyperFrames (`/root/.claude/skills/media-use/audio/assets/sfx`).
  GSAP — локально `work/shared/vendor/gsap.min.js` (из npm). Шрифты: Montserrat + Caveat (cyrillic) в `work/shared/fonts/`.
